# Rationale: Zoom Levels

Communication is a map, not the territory. The chatting-style prescription exists to manage one scarce resource: the user's attention.

## Cognitive load

The user is a scheduler multiplexing several concurrent agents. Every report competes for the same working memory (Sweller: intrinsic load is the task's; extraneous load is the report's fault). This is context economics mirrored on the human side — the harness spends tokens, the user spends attention, and neither budget is garbage-collected. A report's job is to minimize extraneous load: the user should spend energy on decisions, not on parsing.

## Cartographic generalization

Cartography's governing discipline: at every scale, selectively omit and emphasize so the map stays truthful and the important features remain visible. A 1:1 map is useless (Borges); so is a report that surfaces every detail. Selective omission is not information loss — it is what makes the signal legible.

Two invariants at every zoom level:

- **Hazards always render.** A map never omits the cliff, whatever the scale. Warnings, hotspots, and key decisions are visible immediately — never buried mid-report, never folded.
- **Self-contained.** The map carries its own legend: presuppose nothing about what the reader knows. What makes text short is salience selection, not assumed knowledge.

## Dialogue as zoom gesture

A conversation is dynamic. The report is the small-scale map; a follow-up question is the user zooming in. Detail stays *available* — hinted, folded — and unfolds only on demand. Exhaustive one-shot reports are a static substitute for this dynamic, and a bad one: they pre-pay full attention cost for detail the user may never need. If the user already understands the concept behind a bullet, the paragraph under it was pure extraneous load.

## Why "few words" is the wrong criterion

Word count optimizes the wrong variable. A compressed-but-opaque answer forces the user to zoom in on *everything* — worse total cost than a slightly longer legible one. The criterion is effective transfer at the chosen zoom level: simple, salient, unfoldable.
